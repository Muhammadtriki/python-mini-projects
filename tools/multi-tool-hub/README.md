# Multi-Tool Hub

Four small tools behind one menu. The menu keeps running until you choose Quit.

```
python multi_tool_hub.py
```

## Tools

1. **Calculator**: add, subtract, multiply (`*`, `x` or `X`) and divide, with clear errors for bad numbers and division by zero
2. **Caesar cipher**: encrypt or decrypt English text with any shift. Only the letters a to z are shifted, so digits, punctuation, Arabic, Urdu and accented letters pass through unchanged
3. **Palindrome and anagram checker**: ignores spaces, punctuation and capital letters, so "A man, a plan, a canal: Panama" counts as a palindrome
4. **To-do list**: add, show and delete tasks (the list lives in memory and resets when you quit)
